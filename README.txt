웨딩 청첩장 웹사이트

실행 방법
1. wedding_invitation 폴더 안의 index.html을 크롬 또는 엣지로 엽니다.
2. 인터넷 연결 시 Google Fonts가 적용됩니다. 이미지 파일은 images 폴더에 포함되어 있어 별도 이미지 링크가 필요하지 않습니다.
3. 실제 청첩장으로 사용하기 전 index.html에서 이름, 날짜, 예식장, 주소, 계좌번호를 실제 정보로 수정하세요.

구성
- index.html : 페이지 구조와 문구
- style.css : 디자인 및 모바일 반응형 스타일
- script.js : 사진 확대 팝업, 계좌번호 복사 및 안내 팝업, 하트 버튼
- images/ : 참고 시안에서 추출한 웨딩 이미지 파일

지도 버튼은 예시 장소인 '그랜드웨딩홀 서울, 강남구' 구글 지도 검색으로 연결됩니다.
